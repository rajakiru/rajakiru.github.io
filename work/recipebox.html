RecipeBox

A full-stack web application that allows users to store and organize all their recipes in one place.

Key Features

  • View all recipes with search and filter functionality
  • Add new recipes with ingredients, instructions, and images
  • Edit and update existing recipes
  • Organize recipes by categories and cuisines
  • Responsive design for mobile and desktop
